# V10.3 — Studio UX

Design decisions: neutral warm light / charcoal dark surfaces, single green accent, system font, Persian RTL controls, automatic content direction, compact mobile disclosure navigation, accessible keyboard focus and native forms. No external frontend assets. No fake analytics. Catalog counts read from real private inventory. Article filters and forms work without JavaScript. Theme persistence and mobile navigation are progressive enhancements. Profile/project/certificate/media pages are read-only until their separate CRUD milestones; no pretend save or upload controls.

Verification: dedicated browser smoke/axe checks run against an isolated fixture through a loopback-only proxy. No authentication bypass is included in the production HTTP server. Actual Google authorization, TLS, visual human inspection and deployment still require staging.
