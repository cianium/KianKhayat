# گزارش فاز ۳ — طراحی و دسترسی‌پذیری

نسخهٔ قابل بررسی است؛ روی دامنهٔ اصلی منتشر نشده است.

## تغییرات

- طراحی نئوبروتالیسم ملایم با زمینهٔ کرم، سبز و طلایی، قاب تصویر، خطوط مشخص و سایه‌های کوتاه؛ تم تاریک قهوه‌ای با همان ساختار.
- بازطراحی صفحهٔ اصلی، پروژه‌ها، مقاله‌ها، مدارک، تماس، حریم خصوصی، ۴۰۴ و پنجره‌های تعاملی.
- حفظ تعویض تصویر با تم، لودر، انتخاب زبان، حباب مهارت‌ها، فیلتر مدارک، مقاله‌خوان، نمودار گیت‌هاب و فرم EmailJS.
- نمایش کامل نام مهارت‌ها؛ اندازهٔ مناسب دکمه‌ها، فوکوس واضح و پشتیبانی از کاهش حرکت.
- فاصله‌گذاری راست‌به‌چپ و نمایش صحیح نام لاتین، ایمیل و شمارهٔ تلفن در فارسی.
- عنوان کارت پروژه و مقاله به heading تبدیل شد؛ متن عنوان تغییر نکرد.
- ساختار دسترسی‌پذیری ردیف مهارت‌ها و کنتراست لینک‌های ایمیل و نمودار اصلاح شد.

## نتیجهٔ بررسی

- `npm run build`: موفق؛ بدون خطا، هشدار یا hint در بررسی Astro.
- `npm run check:content`: بدون اختلاف تأییدنشده؛ ۱۲ مهارت، ۷ پروژه، ۸ مدرک، ۴ مقاله، ۲۹۰ ترجمهٔ آلمانی و ۲۹۸ ترجمهٔ فارسی حفظ شده است. تغییر تأییدشدهٔ قبلی نام فارسی به نام لاتین همچنان برقرار است.
- ۸ تست مرورگر موفق: مسیرها و تاریخچه، تم و عکس، زبان‌ها، مهارت‌ها، مدارک، مقاله‌ها، فرم با پاسخ شبیه‌سازی‌شده، نمودار و چیدمان.
- `npm run audit:design`: موفق؛ ۲۴ حالت صفحه/پنجره با قواعد خودکار WCAG A/AA و ۳۶ چیدمان در عرض‌های ۳۶۰، ۷۶۸ و ۱۴۴۰ پیکسل بررسی شد. خطای خودکار، بیرون‌زدگی افقی یا هدف لمسی کوچک‌تر از ۴۴×۴۴ در کنترل‌های بررسی‌شده گزارش نشد.
- اسکرین‌شات‌های روشن، تاریک، موبایل فارسی، پروژه‌ها، مقاله‌ها و تماس فارسی بازبینی شدند. فایل `phase3/design-preview.png` نمای کلی طراحی را نشان می‌دهد.

گزارش خودکار، گواهی کامل انطباق WCAG یا آزمون همهٔ مرورگرها و صفحه‌خوان‌ها نیست. جزئیات حالت‌های آزموده‌شده و موارد نیازمند بررسی دستی در `phase3/accessibility.json` ثبت شده است. آزمون‌ها با Chromium انجام شدند. تست تعاملات پیش از اصلاحات نهایی نقش گروه مهارت‌ها، لینک حریم خصوصی و عرض لینک‌های پایین صفحه اجرا شد؛ بررسی طراحی روی نسخهٔ نهایی اجرا شده است.

## موارد مرحلهٔ بعد

جدا کردن خروجی انگلیسی، فارسی و آلمانی، متادیتای کاملاً فارسی برای نسخهٔ فارسی، hreflang متقابل، canonical، sitemap هر زبان و دادهٔ ساختاریافته مربوط به فاز ۴ هستند. انتخاب زبان در این نسخه هنوز در مرورگر انجام می‌شود. زیر‌دامنه‌ها ساخته یا تنظیم نشده‌اند.

هیچ ایمیل واقعی در آزمون‌ها ارسال نشد. ارسال زنده پس از انتشار و تأیید `{{message}}` در متن قالب EmailJS آزمایش می‌شود. ایمیل نمایشی سایت همچنان `cian@kiankhayat.me` است. Lighthouse و ارسال واقعی ایمیل در این فاز اندازه‌گیری نشده‌اند.

برای اجرای محلی: `npm ci`، سپس `npm run build` و `npm run preview`. کد منبع و خروجی `dist/` همراه فایل هستند. خروجی باید با HTTP سرو شود؛ بازکردن مستقیم HTML از فایل مناسب نیست.

فاز ۳ در همین نقطه برای بررسی کاربر متوقف می‌شود.
