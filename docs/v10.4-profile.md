# V10.4 — Profile & media management

Fix Studio CI browser installation: Ubuntu 26.04 was unsupported by Playwright 1.56.1; pin the runner to Ubuntu 24.04 as in the existing portfolio E2E. Reuse locked Sharp via the root npm lockfile; no new dependency version. Use private, content-addressed SQLite media storage with revision-controlled atomic updates. Portraits are decoded, orientation normalized, cropped to 720px square WebP, and metadata is discarded. Local canvas offers five crop positions; not freeform drag/zoom. Resume PDFs are only checked for size, magic and EOF; not malware-scanned and never served inline. Profile changes remain private until public integration. Real Google OAuth, VPS migration and visual review remain outstanding.
